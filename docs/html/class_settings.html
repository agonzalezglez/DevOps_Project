Detailed Description

Simple container for program settings.

This class stores:

  • reference file path
  • input directory path
  • output file path
  • maximum allowed mismatches
  • k-mer size

◆ Settings()

Settings::Settings ( )

Construct default settings.

Default values are chosen to keep the program simple to run.

Default values:

  • output file: output/results/mapping_results.tsv
  • maximum mismatches: 4
  • k-mer size: 9

These values can later be overridden by command-line arguments.
