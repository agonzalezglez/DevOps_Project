Detailed Description

Index structure for a reference genome.

This class wraps a suffix array built on the reference sequence. It provides an interface for retrieving positions of k-mers used during the mapping process.

Construct a reference index from a sequence.

Parameters
referenceSequenceInput genome sequence
kSize of k-mers used during mapping

The constructor performs two main tasks:

  1. normalize the reference sequence
  2. build a suffix array on the normalized reference

The value of k is also stored because the mapper uses the same index together with a fixed k-mer size.

Important: this class does not extract k-mers by itself. It only stores the indexed reference and supports exact pattern search.

Get positions of a k-mer in the reference.

Return all exact positions of a pattern in the reference.

Parameters

Vector of positions

The pattern is first normalized so that search is consistent with the normalized reference stored in the index.

Then the actual search is delegated to the suffix array.

This means that the class acts as a interface between:

  • the mapper, which asks for pattern positions
  • the suffix array, which performs the exact search

This method can also search any exact pattern of any length.

vector< pair< int, bool > > ReferenceIndex::getPositionsOnBothStrands ( const std::string & kmer) const

Get positions on both strands.

Return positions of a pattern on both strands.

Parameters
kmerQuery substring
Returns
Vector of (position, isReverseStrand)

This method searches:

  • the pattern itself on the forward strand
  • its reverse complement on the opposite strand

The returned boolean indicates the strand:

  • false = forward strand
  • true = reverse strand

If the reverse complement is identical to the original pattern, it is not searched twice in order to avoid redundant work.

This method is useful for situations where the caller wants a strand-aware search directly from the reference index.

string ReferenceIndex::getReverseComplement ( const std::string & kmer) const
private

Compute the reverse complement of a pattern.

This method is useful because a read or one of its k-mers may appear on the opposite strand of the reference.

The sequence is:

  • normalized
  • read from right to left
  • complemented base by base

Complement rules used here:

  • A <-> T
  • C <-> G
  • N -> N

char ReferenceIndex::normalizeBase ( char c)
staticprivate

Normalize one nucleotide in DNA mode.

This function simplifies the alphabet used by the project:

  • lowercase letters are converted to uppercase
  • U is converted to T
  • N remains N
  • any unknown character is converted to N

The goal is to keep a consistent internal representation for sequence comparison and pattern search.

string ReferenceIndex::normalizeSequence ( const std::string & seq)
staticprivate

Normalize a full sequence.

This method applies normalizeBase() to every character of the input. It is used both for the reference and for searched patterns, so that all exact comparisons are performed on the same alphabet.

Example:

  • "acgu" becomes "ACGT"
  • unknown symbols become 'N'
