Detailed Description

Specialized reader for FASTQ files.

This class reads FASTQ records and converts them into BiologicalSequence objects.

It extends the generic FileReader by implementing:

  • FASTQ format validation
  • FASTQ-specific parsing

BiologicalSequence FastqFileReader::nextSequence ( )
overridevirtual

Read the next sequence from the FASTQ file.

Read the next sequence from a FASTQ file.

Parsing strategy:

  • locate a header line starting with '@'
  • accumulate sequence lines until '+' is found
  • accumulate quality lines until lengths match the sequence

The method returns a BiologicalSequence containing:

  • description
  • sequence
  • quality scores

Limitations:

  • does not validate quality score encoding (ASCII range)
  • assumes file is not corrupted
Returns
Parsed BiologicalSequence, or an empty object if reading fails

Steps:

  1. find the description line starting with '@'
  2. accumulate sequence lines until '+' is found
  3. accumulate quality lines until quality length matches sequence length
