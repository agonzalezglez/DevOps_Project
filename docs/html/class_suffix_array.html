Detailed Description

Suffix array structure for exact substring search.

This class stores:

  • the indexed reference string
  • the suffix array
  • the LCP array (Longest Common Prefix array)

It provides methods to:

  • check whether a pattern appears
  • count pattern occurrences
  • return all exact occurrence positions

Find one occurrence of a query in the suffix array.

Find one occurrence of a query by binary search.

This method performs a binary search over the sorted suffixes. If one occurrence exists, it returns one matching position in the suffix-array interval.

Parameters

Returns
Position in the suffix array, or -1 if absent

This method searches the ordered suffix array for one suffix that starts with the query.

If a match is found, the returned position is not necessarily the first or the last one. The full interval is later recovered with the LCP array.

std::vector<size_t> SuffixArray::_lcp
private

Longest Common Prefix array.

LCP[i] stores the common prefix length between:

  • suffix starting at SA[i]
  • suffix starting at SA[i+1]

The last value is set to 0 by convention.
