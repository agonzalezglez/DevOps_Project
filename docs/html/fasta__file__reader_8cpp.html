Detailed Description

Implementation of the FastaFileReader class.

Author
Alondra GONZALEZ
Date
2026

This file implements a reader for FASTA sequence files.

Steps:

  • locate a header line
  • accumulate all following sequence lines
  • stop when a new header is found

The parsed sequence is returned as a BiologicalSequence object.

Check whether a line is a FASTA header.

In the most common FASTA format, headers begin with '>'. This implementation also accepts ';' because it can appear in older or course-related examples.
