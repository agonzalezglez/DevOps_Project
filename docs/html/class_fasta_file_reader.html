Detailed Description

Specialized reader for FASTA files.

This class reads one FASTA sequence at a time and returns it as a BiologicalSequence object.

It also keeps a pending header when the next sequence header is read before the current parsing step is finished.

BiologicalSequence FastaFileReader::nextSequence ( )
overridevirtual

Read the next FASTA sequence from the file.

Read the next sequence from the FASTA file.

Steps:

  • find the next header line
  • collect sequence lines until the next header or end of file
  • build and return a BiologicalSequence object
Returns
Parsed sequence, or an empty BiologicalSequence if none is available

Steps:

  1. find the header of the next sequence
  2. remove the leading header marker ('>' or ';')
  3. accumulate sequence lines until:
    • another header is found
    • or the end of file is reached
  4. build a BiologicalSequence object from the collected data

The method also uses a "pending header" mechanism: if the header of the next sequence is encountered while reading the current sequence, it is stored and reused during the next call.

Sequence cleaning behavior:

  • empty lines are ignored
  • whitespace inside sequence lines is ignored
  • letters are converted to uppercase
  • characters must belong to the extended DNA alphabet
  • if ';' appears inside a sequence line, the rest of that line is ignored

Default type behavior:

  • if no type was explicitly requested, EXTENDED_DNA is used by default
Returns
Parsed BiologicalSequence, or an empty object if no sequence remains

Step 1: determine which header to use.

Either:

  • reuse a pending header already read previously
  • or search for the next header in the file

If no header is found, there is no sequence left to read.

Remove the header marker and clean the description.

Step 2: read sequence lines until the next header or end of file.

If a new header is found, it belongs to the next sequence. Store it for the next call and stop reading the current sequence.

Process current sequence line character by character.

This allows:

  • ignoring internal whitespace
  • converting to uppercase
  • stopping if ';' is used as an inline comment marker
  • rejecting invalid symbols

In some FASTA variants, ';' may start a comment inside a line. In this implementation, the rest of the line is ignored.

Step 3: build the final BiologicalSequence object.

If no type was explicitly requested, use EXTENDED_DNA by default. This is a convenient default for genomic FASTA files.

If the sequence is incompatible with the requested type, emit a warning if warnings are enabled.
