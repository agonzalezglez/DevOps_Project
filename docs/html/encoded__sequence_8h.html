Detailed Description

Compact encoding of a nucleotide sequence.

This class stores DNA sequences using 2 bits per nucleotide. It allows storing 4 nucleotides in 1 byte.

Note: This class is not currently used in the mapping pipeline. It represents a memory optimization for large genomes.
