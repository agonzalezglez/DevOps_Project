Detailed Description

Representation of a biological sequence.

This class is used as a container for sequence data. It can represent:

  • DNA
  • extended DNA
  • RNA
  • extended RNA
  • amino acid sequences

The class also stores an optional quality string, which is useful for FASTQ data.

Main goals of this class:

  • provide one common object for FASTA and FASTQ readers
  • normalize input sequences
  • offer basic validation methods

Estimate error probability from one quality symbol.

  • p = 10^(-Q / 10)
